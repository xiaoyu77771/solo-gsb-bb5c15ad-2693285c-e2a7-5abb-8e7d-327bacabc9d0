# 舞台换景口令沙盘

以「口令图」编排舞台换景流程：每个口令有**持续时长**，每条依赖约束表示「前置口令完成后至少等待 N 秒」。编辑后**实时重算**所有口令的最早执行时间；出现**环依赖**时保留上次有效排程并高亮成环路径。支持按排程**模拟执行**（暂停 / 继续 / 重置），编辑导致排程变化时会同步更新尚未执行的口令。数据持久化到本地文件。

技术栈：React + TypeScript（前端，Vite）· Node.js + Express（后端）· 本地 JSON 文件持久化。

## 启动（单条命令）

```bash
docker compose up --build
```

依赖安装、前后端构建与种子数据初始化均随启动自动完成。

## 访问地址

| 项目 | 地址 |
| ---- | ---- |
| 应用（前端 + API） | http://localhost:8080 |
| 健康检查 | http://localhost:8080/api/health |

端口：**8080**（宿主机）→ 8080（容器）。数据保存在 Compose 命名卷 `sandbox-data` 中，容器重建不丢失。

## 功能说明

- **口令编辑**：名称、持续时长（秒），即改即存（防抖写回）。
- **依赖约束**：前置口令 → 后续口令 + 至少等待秒数；不允许自依赖与重复依赖。
- **实时重算**：任意调整后立即按拓扑序前推重算最早开始/结束时间，时间轴同步刷新。
- **环依赖处理**：检测到环时保留上次有效排程，红色高亮成环的口令与依赖边，并展示成环路径；解除环后自动恢复实时排程。
- **模拟执行**：按当前有效排程运行模拟时钟（1×/2×/4× 速度），可暂停、继续、重置；执行中编辑图时，未开始的口令自动采用新排程（新开始时刻已过则立即开始），已开始/已完成的保持原时间。

## 本地开发（可选，无需 Docker）

```bash
npm --prefix server install && npm --prefix web install
npm run dev:server   # 终端 1：后端 http://localhost:8080
npm run dev:web      # 终端 2：前端 http://localhost:5173（/api 已代理到 8080）
```

## API 概览

| 方法 | 路径 | 说明 |
| ---- | ---- | ---- |
| GET | `/api/graph` | 获取口令图 |
| POST / PUT / DELETE | `/api/commands[/:id]` | 口令增改删（删除时级联清理相关依赖） |
| POST / PUT / DELETE | `/api/edges[/:id]` | 依赖约束增改删 |

数据文件：`server/data/graph.json`（容器内 `/app/data/graph.json`），首次启动自动写入示例换景流程。
